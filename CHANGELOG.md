# Changelog

## 0.2.0-beta — 2026-11-04

- Added an in-game Korean name keyboard with touch and button navigation.
- Added Hangul composition, compound vowels/finals and composition-aware deletion.
- Confirming a name preserves its final pending syllable.
- Expanded generated font support to all 11,172 modern Hangul syllables.
- Replaced remaining English poetry fragments and localized special-poem artwork.
- Added a reproducible local build procedure and CIA packaging with independent hash checks.
- Separated private playable files from the source-only GitHub upload folder.

The version remains beta pending physical 3DS and complete route/endings testing.
