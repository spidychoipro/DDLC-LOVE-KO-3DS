# 메뉴 위 검은 선: 0.2.9

실기에서 0.2.8의 좌표/쿼드 변경만으로 해결되지 않았습니다.

원본 menu_bg.png는 552×528 팔레트 PNG입니다. 구형 LovePotion의 Image::Decode는 이를 1024×1024 선형 버퍼에 옮길 때 원본 행만 기록하고 나머지 메모리를 초기화하지 않은 채 전체를 GPU에 전송합니다. 코드상 미기록 영역은 3,028,480바이트입니다. 0.2.8은 이 로딩 경로를 바꾸지 않았습니다.

0.2.9는 빌드 시 원본의 좌측 상단 512×512를 RGBA로 저장합니다. 화면에 쓰는 모든 원본 픽셀은 그대로이며, 가장 먼 쿼드도 x=81..481, y=81..321로 이미지 안에 들어갑니다. 엔진 할당 크기와 이미지 크기가 같아 미초기화 패딩이 없어집니다. 배경에는 nearest 필터를 명시합니다.

검사는 원본 픽셀 일치, RGBA 불투명도, 미기록 패딩 0, 모든 스크롤 범위와 기존 런타임 회귀를 확인합니다. 이 메모리 결함이 영상 속 선의 유일한 원인이라고 확정한 것은 아닙니다. 실기 결과는 사용자 확인이 필요합니다.
