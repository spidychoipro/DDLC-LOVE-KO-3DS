# 3DS 실기 첫 실행 10016 정지 대응

0.2.6의 실기 최초 실행에서 10016번 안내 화면, 빈 대사창과 검은 위 화면 상태로 정지한 사용자 보고에 대한 수정입니다. 재부팅 후 HOME와 다른 게임은 정상으로 확인됐습니다.

0.2.9은 한글을 그리는 도중에 글꼴 이미지를 업로드하던 경로를 제거하고 초기화/업데이트 단계에서 준비합니다. 그리기 콜백에서는 준비된 이미지와 쿼드만 사용합니다. 일반 글꼴은 256x256 텍스처 5개(1.25 MiB), 작은 안내 글꼴은 0.25 MiB이며, 이름에 추가 글자가 필요하면 업데이트 중 준비합니다.

GPU 업로드를 draw 콜백에서 금지하는 회귀 검사와 에뮬레이터의 구형 3DS 설정/새 저장 데이터 첫 실행 검사에서 10016 한글 안내가 그려지고 A로 10017까지 진행되는 것을 확인했습니다. 이후 사용자가 0.2.7의 실기 최초 실행이 정상 동작한다고 확인했습니다. 0.2.9의 메뉴 위 검은 선 수정은 별도 실기 확인이 필요합니다.

## 실기 확인

새 CIA로 업데이트하고 재실행합니다. 기존 저장 파일은 삭제하지 않습니다. New 3DS/XL에서 Luma의 New 3DS CPU를 강제로 Clock+L2/L2로 설정했다면 Off로 두고 확인합니다. [Luma의 공식 설정 설명](https://github.com/LumaTeam/Luma3DS/blob/master/sysmodules/rosalina/data/config_template.ini)은 Clock+L2가 일부 게임의 숨은 버그를 드러낼 수 있다고 안내합니다.

여전히 멈추면 SD의 다음 파일을 확인하면 마지막으로 완료한 글꼴 준비 단계와 첫 실행 상태를 알 수 있습니다.

`/3ds/data/LovePotion/DDLC-3DS-KO/hardware-startup.log`

진단 기록에는 이름이나 저장 내용 대신 시작 단계와 글꼴 페이지 번호를 기록합니다.
